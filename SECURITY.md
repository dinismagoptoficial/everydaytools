# Segurança / Security

Mantém a instalação, o Docker e o kernel atualizados. O projeto aplica correções à versão atual; não mantém ramos de suporte prolongado.

Para comunicar uma vulnerabilidade, usa o canal privado de segurança do repositório, se estiver disponível. Em alternativa, contacta [Dinis Mago](https://github.com/dinismagoptoficial) pelos contactos publicados no perfil. Não publiques documentos, credenciais ou passos de exploração num issue público antes de combinar a divulgação.

Inclui a versão, o ambiente, o comportamento observado e uma reprodução com ficheiros de teste. Os controlos e limites estão em [docs/security.md](docs/security.md).

Keep the installation, Docker and host kernel updated. Security fixes target the current version; there are no long-term support branches.

Report vulnerabilities through the repository's private security channel where available, or contact [Dinis Mago](https://github.com/dinismagoptoficial) using the contact details on the profile. Do not post documents, credentials or exploit instructions in a public issue before agreeing on disclosure.

Include the version, environment, observed behaviour and a reproduction using test files.
